### 问题1：总养户数的统计口径

| 项目 | 内容 |
|------|------|
| **问题ID** | Q001 |
| **问题描述** | 总养户数是统计所有养户，还是只统计"在养"状态的养户？ |
| **影响指标** | M006（总养户数）、C001（生产异常农户占比） |
| **影响说明** | 如果只统计"在养"状态，需要在计算时增加过滤条件 `fk_wens_status = '1'` |
| **数据来源** | wens_rearer_farm_pig 表的 fenable 字段 |
| **状态** | ✅ 已确认 |
| **确认答案** | 统计所有使用状态为"可用"的养户（fenable = '1'）并且饲养状态为"在养"的养户（fk_wens_status = '1'）并且单据状态为已审核（fstatus='C'） |

**计算逻辑：**
```sql
count(distinct fmasterid)
where fenable = '1'
  and fk_wens_status = '1'
  and fstatus = 'C'
```

### 问题2：7天复发率的判断逻辑

| 项目 | 内容 |
|------|------|
| **问题ID** | Q002 |
| **问题描述** | 7天复发率的判断条件中，"预警状态一致"是否需要排除"已关闭"状态？ |
| **影响指标** | M012（复发记录数）、C004（7天复发率） |
| **影响说明** | 如果不排除已关闭状态，可能会将正常关闭后重新触发的预警也计算为复发 |
| **数据来源** | wens_production_anomaly 表的 fk_wens_status 字段 |
| **状态** | ✅ 已确认 |
| **确认答案** | 不需要排除，包含所有状态，只要7天内有相同条件的预警即为复发 |

**判断逻辑：**
- 组织、养户、猪群编码、预警指标、预警等级一致
- 预警触发时间相隔不超过7天
- 不排除"已关闭"状态

### 问题5：有效干涉率的计算口径

| 项目 | 内容 |
|------|------|
| **问题ID** | Q005 |
| **问题描述** | 有效干涉率是按巡查工单数量计算，还是按预警记录数量计算？ |
| **影响指标** | C003（有效干涉率） |
| **影响说明** | 如果按工单数量计算，分母是工单总数；如果按预警记录计算，分母是预警总数 |

```sql

```
